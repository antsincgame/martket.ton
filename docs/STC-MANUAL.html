Фаза 3 · Ключи провайдеров (твои аккаунты) средний · ~30 мин

TONAPI_KEY — бесплатный ключ на tonconsole.com: снимает рейт-лимиты верификации платежей.
VIRUSTOTAL_API_KEY — ключ с virustotal.com: включает антивирус-гейт скачиваний (сейчас фолбэк).
AMLBOT_ACCESS_ID / AMLBOT_ACCESS_KEY — кабинет amlbot.com: включает реальный AML-скоринг (сейчас fail-open, все проходят). Вердикты сразу появятся в новой админ-таблице.
SENTRY_DSN / VITE_SENTRY_DSN — проект на sentry.io: алерты об ошибках.

После каждого ключа — Redeploy; AML-панель админки (с COMMERCE_ADMIN_SECRET) показывает enabled=yes.

Фаза 4 · Telegram Mini App — 5 минут до 900M аудитории низкий · ~10 мин

1. @BotFather → /newbot (если бота нет) → /newapp → URL https://tonforge.org → короткое имя (напр. store).
2. Полученную ссылку (вида https://t.me/имябота/store) — в Coolify env VITE_TG_BOT_URL → Redeploy.

Витрина открывается в Telegram во весь экран с тёмной шапкой; работает и в web.telegram.org; после подписи в кошельке пользователь возвращается в Mini App.

Фаза 5 · Testnet E2E — продавец, затем покупатель-агент средний · 2–4 ч

Продавец: Lite KYC → привязка кошелька → селлерский токен → агентом: продукт → модерация → листинг → дистрибуция → покупка человеком → минт NFT → скачивание.
Покупатель-агент: кошелёк на agents.ton.org (owner-ключ у тебя) → покупательский токен через UI (Commerce → API Tokens → Buyer agent tokens) → два MCP рядом (tonforge-agent-mcp + npx @ton/mcp@alpha) → петля create_order → оплата (ТОЧНО amountNanoton + stateInit + payload!) → confirm → download.
Если выпуск токена даёт AGENT_WALLET_NOT_OWNED — альфа-контракт не отвечает на get_nft_data как ожидалось. ТОЛЬКО для testnet: BUYER_AGENT_OWNERSHIP_CHECK=off, и принеси Когитатору точный reason — адаптер будет переписан. В mainnet «off» не несут никогда.

Лицензия сминчена на агентский кошелёк; sha256 скачанного совпал; вердикты AML видны в админ-панели.

Фаза 6 · Публикация MCP-пакета низкий · ~30 мин

1. npm login (аккаунт с 2FA).
2. cd mcp-server && npm publish (LICENSE и сборка уже готовы).
3. Реестр MCP: mcp-publisher login github → mcp-publisher publish (манифест готов: io.github.antsincgame/tonforge-agent).

npx tonforge-agent-mcp@latest стартует у любого агента мира.

Фаза 7 · Контракты: передеплой + внешний аудит ВЫСОКИЙ · дни

1. Деплой новых Escrow/AppCollection/LicenseItem на testnet (contracts/scripts/); обновить BOC-env (Когитатор пересоберёт по слову) и адрес коллекции; повторить Фазу 5.
